## [0.7.0](https://github.com/gelzinn/ai-status/compare/v0.6.1...v0.7.0) (2026-07-11)

### Features

* **install:** configure bar icons and display preferences in an installation wizard, back up the existing Waybar configuration and restore it with `ai-status revert` ([#23](https://github.com/gelzinn/ai-status/pull/23), [9387360](https://github.com/gelzinn/ai-status/commit/9387360f5dce47ebe566d025bb55069d8103d175)).
* **waybar:** select individual provider metrics, including Claude's separate weekly limits, and show the same detailed tooltip when hovering over the text or provider logo ([#23](https://github.com/gelzinn/ai-status/pull/23)).
* **web:** redesign the landing page and provider catalog and provide the shorter `/install` URL for installation commands ([#23](https://github.com/gelzinn/ai-status/pull/23)).

### Bug Fixes

* **install:** handle URLs and trailing commas in Waybar configuration, avoid duplicate modules, guard unsupported multi-bar configurations and finish setup with defaults in headless or cancelled-wizard cases ([#23](https://github.com/gelzinn/ai-status/pull/23)).
* **waybar:** preserve display preferences during loading, keep tooltip layouts stable and synchronize text and logo when the selected provider changes ([#23](https://github.com/gelzinn/ai-status/pull/23)).

### Performance Improvements

* **usage:** display each provider's result as it arrives instead of waiting for the slowest provider to finish refreshing ([#23](https://github.com/gelzinn/ai-status/pull/23)).
* **install:** install only the desktop library and shared provider data, leaving website dependencies, build output and Git metadata out of the installed copy ([#23](https://github.com/gelzinn/ai-status/pull/23)).

### Documentation

* update installation and provider guides for the wizard, logo tooltips, per-model metric selection and Codex's five-hour and weekly limits ([#23](https://github.com/gelzinn/ai-status/pull/23)).

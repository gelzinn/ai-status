# Usage display preference

These previews use the production Quickshell pages and Python snapshot builder
with sample Codex, Cursor and Grok Bot data. Qt Quick Test renders them offscreen
with the repository's shell fixtures and waits for progress animations to finish.
The fixture supplies a monospace font and square corners; a running Omarchy
desktop supplies its own theme.

- `used.png`: the default consumption view, including an exhausted Codex quota.
- `remaining.png`: the same data and selection with remaining quota selected.
- `settings.png`: the new Used / Remaining selector in Settings.

Available usage credits and uncapped on-demand spend keep their original values.

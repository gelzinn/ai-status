# Preview artwork

`windows-11-wallpaper.webp` is an optimized copy of the Windows 11 Bloom dark
wallpaper from Microsoft's [Windows 11 press materials](https://news.microsoft.com/june-24-2021/).
The [original image](https://msftstories.thesourcemediaassets.com/sites/612/2021/06/Windows-11-Bloom-Screensaver-Dark-1000x562.jpg)
is © Microsoft and is used to illustrate the Windows desktop preview.

`windows-11.svg` renders the four square panes of the Windows 11 symbol,
referencing the logo in the same Microsoft press materials. It is used for the
preview's Start icon and the Windows installation tabs. The Windows mark belongs
to Microsoft.
